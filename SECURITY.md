# Güvenlik ve gizlilik

Lütfen açık issue veya PR içine token, parola, auth/config dosyası, SQLite DB, session dökümü, gerçek konuşma kimliği veya kişisel dosya yolu eklemeyin. Hata raporunu sentetik örnek ve ayıklanmış hata metniyle hazırlayın. Bu public depo kişisel test kanıtı deposu değildir.

Bağımlılık kontrolleri `npm audit` ve `npm audit --omit=dev` ile yapılabilir. Temiz rapor tüm güvenlik risklerinin ortadan kalktığı garantisi değildir. Beta paket imzasızdır; yalnız bu deponun Releases sayfasındaki dosya ve SHA256 değerlerini kullanın.

Controller yerel Codex sunucusuna bağlanır; açık manuel komut veya etkin otomatik politika gerçek Goal değişikliği ve turn interrupt gönderebilir. İlk kurulumda README'deki kontrollü bağlantı adımlarını izleyin. Loopback sunucusunu dış ağa açmayın.
