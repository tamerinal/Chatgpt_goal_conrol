# Devam çalışma talimatı

Önce PLAN.md, STATUS.md, TEST-GATES.md ve AGENTS.md okuyun. Mevcut kullanıcı değişikliklerini koruyun. Teknik test/build sonuçlarını gerçekten çalıştırarak kaydedin. Yalnız etkin kapsamı uygulayın; eksik canlı kabul kapılarını varsaymayın.

Canlı hedef ve ayar değişimi, kurulum ve yayın için güncel kullanıcı yetkisini kontrol edin. Ekran/düğmeler kullanıcıda kalır. Başka writer'ı devralmayın, approval otomatik kabul etmeyin, belirsiz dispatch'i kör tekrar etmeyin. Kişisel kimlikleri ve test çıktısını public kayda koymayın.

Bu dosya başlı başına yeni Goal oluşturma, canlı komut veya otomatik devam yetkisi vermez. Sonraki adımı STATUS.md'ye yazın.
